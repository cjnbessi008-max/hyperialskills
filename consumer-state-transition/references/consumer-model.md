# Consumer State Model Reference

## State dimensions

Use only dimensions relevant to the current decision.

| Dimension | Low | High | Useful evidence |
|---|---|---|---|
| Problem awareness | no recognized problem | problem is explicit and concrete | search terms, complaint language, diagnostic results |
| Urgency | no near-term reason to act | delay has visible cost | deadlines, repeated pain, recent failure |
| Trust | doubts provider or claim | expects claims to be credible | referrals, repeat engagement, direct trust statements |
| Proof requirement | accepts broad explanation | needs concrete comparable evidence | case-study requests, repeated validation questions |
| Perceived value | upside unclear | outcome feels worth effort/cost | benefit questions, ROI discussion, willingness to proceed |
| Price sensitivity | price is secondary | small price change alters behavior | discount requests, plan comparison, checkout drop-off |
| Friction sensitivity | tolerates effort | abandons with small effort | form abandonment, setup failure, delayed follow-through |
| Switching cost | easy to change | strong operational/emotional cost | contract, migration effort, habit, incumbent dependency |
| Perceived risk | reversible/low consequence | fears loss or failure | guarantee questions, approval delays, implementation concerns |
| Commitment readiness | browsing/exploring | willing to take irreversible action | booking, payment, account creation, signed agreement |

## Example: education service

Observed evidence:
- Parent reads a diagnostic report twice.
- Parent asks whether the same issue appears in students with similar grades.
- Parent opens pricing but does not book consultation.

Possible state:
- problem awareness: high
- urgency: medium
- trust: medium
- proof requirement: high
- price sensitivity: unknown
- commitment readiness: medium

Possible policy:
`If the diagnosis appears specific to my child and there is credible evidence the method works for comparable students, then book consultation.`

Better next action:
Show one comparable, verifiable case or offer a short diagnostic conversation.

Bad next action:
Assume price is the barrier and discount immediately.

## Evidence discipline

Always label each statement as one of:

- **Observed** — directly recorded behavior or statement.
- **Inferred** — plausible explanation supported by evidence.
- **Unknown** — materially relevant but not observed.
- **Testable next** — a low-cost action that can discriminate between competing explanations.

When multiple hypotheses fit the same behavior, list the alternatives rather than forcing one story.
